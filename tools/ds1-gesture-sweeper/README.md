# DS1 Gesture Sweeper

Ищет, **где в сейве DSR лежат флаги разблокировки жестов**, чтобы потом сделать в
редакторе вкладку Gestures по образцу вкладки Bonfires.

Тот же приём, что в `ds3-stat-sweeper`: правим значения **в памяти процесса**
(как это делает Cheat Engine по `1FRDarkSoulsRemastered.CT`, группа
*Gesture Game Data*), заставляем игру сохраниться через **ESC ×2**, дампим
расшифрованный слот и сравниваем дампы между собой.

## Откуда взяты офсеты памяти

Из `1FRDarkSoulsRemastered.CT`:

```
BaseB  = AOB `48 8B 05 ?? ?? ?? ?? 45 33 ED 48 8B F1 48 85 C0`, RIP-relative (+7)
жест i = байт по [[[BaseB]+0x10]+0x568]+0x10 + 4*i
```

Значение байта (из DropDownList'ов CT и скрипта *Unlock All Gestures (AOB)*,
который пишет записи по 4 байта `[value, 00, index, 00]`):

| состояние | значение |
|---|---|
| Locked   | `(i+1)*2`     |
| Unlocked | `(i+1)*2 + 1` |

То есть бит 0 = «разблокирован». Жестов 15, порядок — как в CT.

## Требования

```bash
pip install -r requirements.txt      # pymem, pycryptodome
```

Игра запущена, персонаж **загружен в мир** (не в главном меню), окно в
window/borderless режиме.

## Использование

```bash
python memory.py                      # проверка: адреса + текущее состояние жестов
python sl2.py <DRAKS0005.sl2>         # какие слоты есть в сейве
python main.py --list                 # то же, но с автопоиском профиля

python main.py --out ./out            # полный прогон (слот определяется автоматически)
python main.py --slot 0 --out ./out   # прогон с явным слотом
python main.py --only 0,14            # только два жеста (быстрая проверка)
python main.py --analyse-only --out ./out   # пересобрать report.md по готовым дампам
```

### Что делает полный прогон

1. Все 15 жестов → **Locked**, сейв, дамп → `baseline_all_locked.bin`
2. Для каждого `i`: всё Locked **кроме** `i`, сейв, дамп → `gNN_<slug>.bin`
3. Все 15 → **Unlocked**, сейв, дамп → `final_all_unlocked.bin`
4. Возвращает исходное состояние жестов + финальный сейв (отключается `--no-restore`)
5. `diff.py` строит `report.md`

Перед началом кладёт копию `.sl2` в `--out` (`DRAKS0005.backup.<ts>.sl2`).

### Важно во время прогона

- ESC уходит **в активное окно** — фокус программно не крадём (игра его не
  принимает). Первые 5 секунд идёт отсчёт: разверни игру и больше не трогай
  клавиатуру/мышь до конца прогона.
- Прогон переписывает сейв ~18 раз. Бэкап делается автоматически, но лучше
  запускать на **не-основном** персонаже.

## Как читать `report.md`

Единица анализа — **бит** `(offset, bit)`, а не байт: флаги жестов почти
наверняка упакованы по битам в один-два байта, как костры в
`Character.getBonfireWarpFlags()`.

- **Биты-кандидаты** — изменились ровно в одном дампе → это и есть флаг жеста.
- **Раскладка по байтам** — готовая карта `bitN = <жест>` + относительные офсеты
  от `Pattern1`, которые надо прописать в `Character.ts`.
- **Шум** — биты, изменившиеся во всех дампах (таймер игры, позиция и т.п.).
- **Контроль** — дифф all-locked → all-unlocked; должен совпасть с объединением
  битов-кандидатов.

Все офсеты дампов **совпадают с офсетами в `src/apps/ds1/lib/Character.ts`**:
слот расшифровывается с тем же сдвигом +16, что и в редакторе (MD5 идёт в AES
как IV — см. комментарий класса в `SaveFileEditor.ts`).

## Выбор слота

Игра переписывает только затронутые слоты `.sl2`. Если верифицировать не тот
слот, все дампы окажутся байт-идентичны и дифф будет пустым (ровно на эти
грабли наступил DS1 Save Watcher). Поэтому `--slot` по умолчанию = `auto`:
после первого сейва скрипт смотрит, какой слот персонажа игра переписала, и
дальше работает с ним. Слот 10 (настройки) из автодетекта исключён.

## Результат прогона (2026-09-12, слот 2 профиля 806879225)

17/17 сейвов прошли, карта получилась 1:1 — каждый жест забрал ровно один бит,
больше в слоте не сдвинулось ничего.

**В сейве блок лежит ровно так же, как в памяти:** 15 записей
`[u16 value][u16 index]` подряд, затем терминатор `FE FF FF FF`.

```
0x1E4A8: 02 00 00 00  04 00 01 00  06 00 02 00  08 00 03 00   <- все locked
0x1E4A8: 03 00 00 00  05 00 01 00  07 00 02 00  09 00 03 00   <- все unlocked
...
0x1E4E4: FE FF FF FF                                          <- терминатор
```

| | |
|---|---|
| офсет блока | **`0x1E4A8`**, абсолютный (в координатах редактора, со сдвигом +16) |
| шаг записи | 4 байта |
| записей | 15 |
| флаг «разблокирован» | бит 0 первого байта записи |

**Важно: якорь — абсолютный, а не от `Pattern1`.** Сначала офсет записался как
`p1-0xCD6`, но проверка на всех локальных сейвах это опровергла: расстояние до
Pattern1 гуляет между персонажами (`p1-0xCD6` … `p1-0xD7E`), а абсолютный
`0x1E4A8` совпал во **всех 26 персонажах шести профилей**. Поэтому в
`Character.findGestureTable()` сделано так: пробуем `0x1E4A8`, проверяем
структуру записей, и только если не сошлось — сканируем слот по сигнатуре.

## Файлы

| Файл | Назначение |
|---|---|
| `constants.py` | офсеты памяти из CT, имена жестов, константы `.sl2` |
| `memory.py` | резолв BaseB (AOB) + чтение/запись байтов жестов |
| `input_save.py` | ESC ×2 через SendInput (scancode) + ожидание записи сейва |
| `sl2.py` | расшифровка слотов DSR, поиск Pattern1, имя/уровень |
| `diff.py` | побитовый анализ дампов → `report.md` |
| `main.py` | драйвер прогона |
